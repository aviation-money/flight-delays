# Цена задержки

Сайт, который раз в час собирает табло вылетов аэропортов России, считает суммарные минуты задержки за сегодня и переводит их в рубли. Аэропорты сортируются по минутам, по рублям или по потерям на один рейс.

Всё работает бесплатно на GitHub: GitHub Actions запускает сборщик каждый час, данные хранятся в репозитории, сайт публикуется через GitHub Pages. Свой сервер не нужен.

## Как устроено

```
config/airports.json       список аэропортов (IATA, название, часовой пояс)
config/methodology.json    все коэффициенты перевода минут в рубли
collector/collect.py       сборщик (Python 3.9+, без зависимостей)
docs/index.html            сайт (один файл, без сборки)
docs/data/latest.json      сводка, которую показывает сайт
docs/data/history.json     почасовые срезы за последние 7 дней (для графика)
docs/data/flights/IATA/YYYY-MM-DD.json   все вылеты дня по аэропорту (хранятся 30 дней)
.github/workflows/collect.yml   ежечасный запуск + публикация на Pages
```

Каждый запуск сборщик запрашивает вылеты за окно «последние 4 часа + следующий час» и сливает их с уже собранными за день. Так фактические времена вылета уточняются, а запросов к API тратится минимум. В первый запуск суток окно начинается с 00:00 местного времени.

## Источник данных

**AeroDataBox** (FIDS, табло вылетов). Это официальный коммерческий API с покрытием российских аэропортов: плановое время, уточнённое/фактическое время, статус, тип самолёта. Подключается через RapidAPI или API.market.

Расход: один аэропорт в час = 1 запрос (2 «юнита» тарифа), то есть около 1 440 юнитов в месяц на аэропорт. 24 аэропорта из списка = ~35 000 юнитов в месяц. Бесплатного тарифа на это не хватит, поэтому:
- либо сократите список через переменную `AIRPORTS` (например `SVO,DME,VKO,LED,AER`),
- либо возьмите платный тариф с нужным объёмом. Актуальные цены: https://aerodatabox.com/pricing/

Без ключа сборщик работает в режиме `demo` и генерирует правдоподобные синтетические данные. Сайт в этом режиме помечен плашкой «Демо-данные».

Почему не сайты аэропортов напрямую: у каждого свой формат, они часто меняются и многие недоступны с зарубежных IP, а серверы GitHub Actions находятся за рубежом. Источник легко заменить: достаточно написать класс с методом `departures(iata, start, end, tz)` в `collector/collect.py`.

## Методика

Считаются только **вылеты**, чтобы одни и те же минуты не попадали в сумму дважды (задержка прилёта обычно продолжает задержку вылета в другом аэропорту). «Сегодня» значит местные сутки аэропорта.

- Минуты задержки рейса = фактическое (уточнённое) время отправления − плановое. Ранний вылет = 0.
- Рейс ещё не вылетел, а плановое время прошло: учитываются минуты, накопленные к моменту обновления.
- Отменённые рейсы считаются отдельно и в рубли не переводятся.

Деньги:

```
пассажиры    = кресла × загрузка (0.88)
потери_пасс  = пассажиры × минуты / 60 × 600 ₽/час
потери_авк   = кресла × минуты × 55 ₽
потери       = потери_пасс + потери_авк
```

Количество кресел определяется по типу самолёта из табло (`seats_by_model`), если тип неизвестен, берётся 150.

Откуда коэффициенты:
- **600 ₽ за час времени пассажира**: средняя начисленная зарплата в РФ около 100 000 ₽ в месяц (Росстат) / ~165 рабочих часов.
- **Загрузка 88%**: занятость кресел у российских авиакомпаний в 2025 году была около 88–90% (Росавиация).
- **55 ₽ за кресло-минуту** (≈ 9 000 ₽ в минуту для A320): EUROCONTROL Standard Inputs for CBA, глава 16 «Cost of delay», средняя стоимость минуты тактической задержки у гейта для авиакомпании €166 (все задержки) и €45 (до 30 минут), цены 2022 года; для A320 около €100–110. Для России взят более консервативный уровень. Для сравнения, RunAvia оценивает задержку B737 более чем на 15 минут примерно в 1,5 млн ₽ с учётом недополученной выручки (Коммерсантъ, 2025), то есть наша оценка скорее занижена.

Все числа меняются в `config/methodology.json` и сразу показываются на сайте в разделе «Как считаются потери».

## Запуск

1. Создайте репозиторий на GitHub и положите туда эти файлы.
2. **Settings → Pages → Source: GitHub Actions.**
3. **Settings → Secrets and variables → Actions:**
   - секрет `AERODATABOX_KEY` с ключом RapidAPI (без него будет демо-режим);
   - переменная `AIRPORTS` (необязательно), например `SVO,DME,VKO,LED,AER`;
   - переменная `AERODATABOX_BASE` (необязательно), если ключ от API.market, а не RapidAPI.
4. **Actions → «Сбор задержек и публикация сайта» → Run workflow.** Дальше всё запускается само каждый час.

Локально:

```
FLIGHT_SOURCE=demo python3 collector/collect.py
cd docs && python3 -m http.server 8000
```

Ограничение GitHub: расписание cron может запускаться с опозданием до 10–15 минут, а в неактивных репозиториях (60 дней без коммитов) отключается. Здесь коммиты с данными идут каждый час, так что отключения не будет.
